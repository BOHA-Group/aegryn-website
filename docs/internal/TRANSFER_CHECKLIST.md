## Phase 1, Pre-Certification

| # | Action | Owner | Status |
|---|---|---|---|
| 1.1 | Seller submission received (form + fee paid) | Seller | ☐ |
| 1.2 | Asset pre-screened by Aegryn (sector, ARR range, viability) | Aegryn | ☐ |
| 1.3 | NDA signed by seller | Seller | ☐ |
| 1.4 | CIFS certifier assigned | Aegryn | ☐ |
| 1.5 | Data room access granted to certifier | Aegryn | ☐ |
| 1.6 | Document checklist transmitted to seller (C-01→S-09) | Aegryn | ☐ |
| 1.7 | All required documents uploaded by seller | Seller | ☐ |

**Go/No-go:** All required documents present and NDA signed → proceed to Phase 2

## Phase 2, Certification (CIFS Audit)

| # | Action | Owner | Status |
|---|---|---|---|
| 2.1 | Dimension C (Code) evaluated | Certifier | ☐ |
| 2.2 | Dimension I (IP & Rights) evaluated | Certifier | ☐ |
| 2.3 | Dimension F (Finance) evaluated | Certifier | ☐ |
| 2.4 | Dimension S (Security) evaluated | Certifier | ☐ |
| 2.5 | Grade engine run, score computed | Aegryn (admin) | ☐ |
| 2.6 | Auto-refusal check passed | Aegryn | ☐ |
| 2.7 | Grade validated and signed off by Aegryn | Aegryn | ☐ |
| 2.8 | Grade report transmitted to seller | Aegryn | ☐ |
| 2.9 | Asset dossier built (teaser + full dossier) | Aegryn | ☐ |
| 2.10 | `AEGRYN_CERTIFICATE.md` generated for asset handover | Aegryn | ☐ |

**Go/No-go:** Grade ≥ B and no auto-refusal → proceed to Phase 3  
**If refused:** Rejection notice sent, reasons listed, re-certification path communicated

| 3.6 | Private session scheduled (if applicable) | Aegryn | ☐ |
| 3.7 | Buyer expresses formal interest | Buyer | ☐ |
| 3.8 | Seller informed of buyer interest (identity disclosed post-double NDA) | Aegryn | ☐ |
