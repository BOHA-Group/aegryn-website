# Audio source — Aegryn ambient player

Placer ici le fichier source audio :

```
public/audio/ambient.mp3
```

Formats supportés : MP3 (recommandé), AAC, OGG.
Taille recommandée : < 8 Mo (compresser à ~128 kbps pour ambient).
Le fichier est référencé dans `MusicPlayer.tsx` via `/audio/ambient.mp3`.
